# Hello My Cat

무지개별로 여행 간, 사랑하는 내 반려동물과 대화할 수 있는 챗봇입니다. 그리울 때 내 반려동물과 대화를 나눠보세요.

## 주요 기능

### 💬 실시간 채팅
- AI 기반 자연스러운 대화
- 반려동물의 성격과 특징을 반영한 개인화된 응답
- 대화 히스토리 저장

### 🐾 반려동물 프로필 관리
- 반려동물 정보 등록 (이름, 사진, 호칭 등)

### 📝 추억 기록
- 함께한 순간들을 기록하고 저장
- 반려동물과의 소중한 기억 보관

### 💌 일기/편지
- 반려동물에게 편지를 작성하고 읽기
- 읽지 않은 편지 알림 기능

## 시작하기

프로젝트를 클론하고 의존성을 설치한 후, 환경 변수를 설정하세요.

```bash
npm install
```

`.env` 파일에 Gemini API 키를 설정하세요:

```
GEMINI_API_KEY=your_api_key_here
```

## 기술 스택

- Next.js
- React
- TypeScript
- Gemini API
- Tailwind CSS
